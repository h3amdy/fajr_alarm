# مشروع منبه الفجر الذكي بنظام Flutter 📱🕌

تطبيق متكامل مكتوب بلغة **Flutter (Dart)** يحل المشكلة الأكبر في تطبيقات المنبهات على الهواتف الحديثة: **العمل في الخلفية (Background Execution) مع إغلاق التطبيق والشاشة مقفلة (Lock Screen & Doze Mode)**.

---

## 🌟 مميزات المشروع في Flutter:

1. **إيقاظ الهاتف من النوم العميق (Exact Alarm)**:
   - استخدام باقة `alarm` مع `AlarmManager.setAlarmClock()` في أندرويد 12 و 13 و 14.
   - دعم `Full-Screen Intent` لإظهار شاشة الرنين فوق قفل الشاشة مباشرة عند الأذان.
   - استخدام `WakelockPlus` لإبقاء الشاشة مضاءة أثناء أداء مهمة الاستيقاظ.

2. **حساب أوقات الصلاة محلياً 100% دون إنترنت**:
   - عبر خوارزميات `adhan` الفلكية المعتمدة (طريقة أم القرى، وغيرها).
   - إمكانية جدولة المنبه قبل الفجر بـ (5، 10، 15، 30 دقيقة).

3. **مهام الاستيقاظ الصارمة (Anti-Snooze Missions)**:
   - **التسبيح الذكي**: عداد تفاعلي مع ردود فعل لمسية (Haptic Vibration) يمنع الإيقاف حتى إتمام العدد.
   - **الأسئلة الدينية**: بنك أسئلة إسلامية لتنشيط الوعي فور الاستيقاظ.
   - **المسائل الحسابية**: عمليات حسابية بمستويات مختلفة لتنشيط خلايا التفكير.
   - **أذكار الاستيقاظ**: قراءة ذكر الاستيقاظ المأثور وتأكيده.

4. **الأصوات والنغمات المدمجة**:
   - نغمة «قم يا أخي» (أذان وتذكير نبوي).
   - نغمة «الصلاة خير من النوم» (أذان ندي خاشع).
   - نغمة «إن المتقين في جنات» (تلاوة خاشعة مؤثرة).

---

## 🚀 كيفية تشغيل المشروع على جهازك:

### 1. المتطلبات:
- تثبيت Flutter SDK (الإصدار 3.2.0 أو أحدث).
- Android Studio أو VS Code.

### 2. تحميل الحزم:
```bash
cd flutter_project
flutter pub get
```

### 3. تشغيل التطبيق على الهاتف أو المحاكي:
```bash
flutter run
```

## 📂 هيكلية الملفات في Flutter:
```text
flutter_project/
├── pubspec.yaml                      # باقات alarm, adhan, audioplayers, vibration
├── android/
│   └── app/src/main/AndroidManifest.xml # الأذونات الصارمة لـ Android 12+
├── assets/
│   └── audio/                       # ملفات الأصوات mp3
└── lib/
    ├── main.dart                     # نقطة الانطلاق وإعداد اللغة العربية (RTL)
    ├── models/
    │   └── alarm_model.dart          # نموذج البيانات والمهام والنغمات
    ├── services/
    │   ├── prayer_service.dart       # حساب أوقات الصلاة الفلكية
    │   └── alarm_service.dart        # جدولة المنبه الصارم وتشغيل الصوت بالخلفية
    ├── screens/
    │   ├── home_screen.dart          # شاشة المنبه والعداد التنازلي
    │   ├── setup_screen.dart         # ضبط وقت الاستيقاظ والمهمة والنغمة

    └── widgets/
        └── mission_widgets.dart      # ويدجت التسبيح والأسئلة والمسائل الحسابية
```
